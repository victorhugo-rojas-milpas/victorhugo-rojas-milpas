### Hola, soy Víctor Hugo Rojas Milpas 👋

Soy egresado de **Ingeniería en Comunicaciones y Electrónica** en **ESIME Zacatenco (IPN)**, enfocado en **ciberseguridad de redes, desarrollo backend en Linux y electrónica/sistemas embebidos**.

#### 🔧 Tecnologías y herramientas
* **Ciberseguridad y Redes:** Detección de intrusos (IDS), análisis de tráfico con `tshark`, auditoría en Linux (Kali/WSL2), Nginx (proxy inverso), OpenSSL.
* **Lenguajes y Bases de Datos:** Python (Flask, Pandas), C, C++, Node.js (Express), SQL (MariaDB, MySQL).
* **Electrónica y Control:** Diagnóstico y reparación de PCB a nivel componente, microcontroladores (STM32, SAMD21), tableros de control eléctrico.

#### 🚀 Proyecto destacado
* **GuindaNet IDS:** Sistema web inteligente de detección de ciberataques (fuerza bruta, DoS, DDoS y escaneo de puertos) desarrollado con Python, Flask, MariaDB, `tshark` y un modelo de Machine Learning (Random Forest) desplegado sobre Nginx con OpenSSL.
